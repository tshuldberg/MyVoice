# MyVoice Landing Page

Static marketing page for MyVoice.

## Run Locally

From the repository root:

```bash
python3 -m http.server 5500
```

Then open `http://127.0.0.1:5500/website/`.

## Donations

The page links to Buy Me a Coffee (`https://buymeacoffee.com/TreyTre`). To add another
option, such as Venmo, add a link in the `donation-options` block of `website/index.html`
with the real handle. Never publish a placeholder link.
